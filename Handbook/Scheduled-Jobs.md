# Scheduled Jobs

This page documents all of the scheduled jobs that our team maintains.

In general, these jobs send email notifications using AWS SNS when they fail. If you want to receive those notifications, ask a senior staff member to subscribe your email address to the relevant SNS topic.

| Job name                              | Frequency     | Deployment platform                                                                                               | Source repository                                                                      | Description                                                                                                                                                        |
| ------------------------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Service healthchecks                  | Every 3 hours | [GitHub Actions](https://github.com/ccao-data/service-alerts/actions/workflows/check-alerts.yml)                  | [`service-alerts`](https://github.com/ccao-data/service-alerts/)                       | Queries the CloudWatch logs for every job that was scheduled to complete in the past three hours to make sure it ran successfully                                  |
| Spark ingest                          | Daily         | Data team server                                                                                                  | [`service-spark-iasworld`](https://github.com/ccao-data/service-spark-iasworld/)       | Extracts raw tables from iasWorld and loads them into our Athena data lake                                                                                         |
| IC reference file export              | Daily         | Windows VM                                                                                                        | [`data-architecture`](https://github.com/ccao-data/data-architecture/)                 | Queries and exports a set of Athena views containing data that the Industrial and Commercial (IC) Valuations team use as the basis for Excel automations           |
| Town close QC dashboard refresh       | Daily         | Tableau                                                                                                           | [`data-architecture`](https://github.com/ccao-data/data-architecture/)                 | Refreshes Athena data sources for the town close QC dashboard                                                                                                      |
| Residential land QC dashboard refresh | Daily         | Tableau                                                                                                           | [`data-architecture`](https://github.com/ccao-data/data-architecture/)                 | Refreshes Athena data sources for the residential land QC dashboard                                                                                                |
| Appeal workbook export                | Daily         | Windows VM                                                                                                        | [`process-appeal-worksheets`](https://github.com/ccao-data/process-appeal-worksheets/) | Queries for appeals in iasWorld and exports them to Excel for IC analysts to review                                                                                |
| dbt source freshness tests            | Daily         | [GitHub Actions](https://github.com/ccao-data/data-architecture/actions/workflows/test_dbt_source_freshness.yaml) | [`data-architecture`](https://github.com/ccao-data/data-architecture/)                 | Checks upload timestamps for our iasWorld tables in Athena to make sure they have been refreshed recently                                                          |
| Build daily dbt models                | Daily         | [GitHub Actions](https://github.com/ccao-data/data-architecture/actions/workflows/build_daily_dbt_models.yaml)    | [`data-architecture`](https://github.com/ccao-data/data-architecture/)                 | Refreshes a set of Athena views that we have marked in dbt as requiring materialization, so as to reduce the runtime of important queries that rely on those views |
| Data integrity tests                  | Weekly        | [GitHub Actions](https://github.com/ccao-data/data-architecture/actions/workflows/test_dbt_models.yaml)           | [`data-architecture`](https://github.com/ccao-data/data-architecture/)                 | Runs a suite of dbt tests to check our core assumptions about the iasWorld tables that we rely on                                                                  |
| Open data portal upload               | Twice monthly | [GitHub Actions](https://github.com/ccao-data/data-architecture/actions/workflows/socrata_upload.yaml)            | [`data-architecture`](https://github.com/ccao-data/data-architecture/)                 | Extracts data from Athena and pushes it to our Tyler Data & Insights open data portal                                                                              |
| Open data asset tests                 | Monthly       | [GitHub Actions](https://github.com/ccao-data/data-architecture/actions/workflows/test_open_data_assets.yaml)     | [`data-architecture`](https://github.com/ccao-data/data-architecture/)                 | Compares row counts in our Athena views to row counts in our open data assets, to make sure the asset upload completed successfully                                |
